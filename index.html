Guía rápida

Publica esta página y guarda tus datos en GitHub en 4 pasos.

1

Crea un repositorio en GitHub (ej. mis-remesas) y sube este archivo como index.html a la rama main.
Luego: Settings → Pages → Deploy from branch → main → Save. Tu página quedará en tu-usuario.github.io/mis-remesas.

2

Crea un token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. En Repository access elige solo tu repositorio, y en Permissions → Contents selecciona Read and write.
También sirve un token clásico con alcance repo.

3

Conecta el guardado: abre ⚙ aquí mismo, completa usuario, repositorio, ruta (remesas.json) y token. Pulsa Probar conexión y luego Guardar en GitHub.
Se creará el archivo JSON con todos tus registros; podrás descargarlo o restaurarlo desde cualquier equipo.

4

Registra y revisa: la fecha viene en hora de Venezuela pero puedes cambiarla libremente. Usa el filtro Todo / Por día / Por mes / Rango sobre la tabla para revisar el período que quieras. La ganancia se calcula como USD × tasa compra − USD × tasa envío − comisión. Para reiniciar el libro usa ⚙ → Borrar todos los datos.
